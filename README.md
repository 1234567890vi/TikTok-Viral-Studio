# 🚀 Creator & TikTok Viral Studio (Android App)

تطبيق أندرويد احترافي متكامل وعالي الأداء لصناع المحتوى، يجمع بين تحميل فيديوهات التيك توك بدون علامة مائية بأعلى جودة (Full HD / 4K) وصوت MP3، وبين أدوات ذكية لصناع المحتوى تعتمد على بنية هجينة متقدمة (**Kotlin + Jetpack Compose + C++ Android NDK + Python Engine**).

---

- **واجهة المستخدم (Frontend / UI)**:
  - أحدث معايير **Jetpack Compose** و **Material 3**.
  - دعم كامل لشاشات التردد العالي (120Hz Smooth Transitions).
  - وضع ليلي فاخر (`#0F0F13`) مع ألوان نيون مستوحاة من هوية تيك توك وتأثيرات زجاجية شبه شفافة (Glassmorphism).
  - دعم أصيل للغة العربية من اليمين لليسار (RTL).

- **محرك الأداء الفائق (C++ via Android NDK & JNI)**:
  - ملف البناء: `app/src/main/cpp/CMakeLists.txt`
  - الكود المصدري: `app/src/main/cpp/native-downloader.cpp`
  - التخاطب عبر JNI: `com.creator.tiktokstudio.core.NativeEngine`
  - المهام: حساب سرعة التحميل اللحظية بالميغابايت بدقة عالية، تشفير وتدقيق أكواد الـ VIP، وتنظيف وتأمين أسماء الملفات.

- **محرك البايثون (Python Engine)**:
  - الكود المصدري: `app/src/main/python/tiktok_extractor.py` (ومنسوخ إلى `assets/python/`)
  - المهام: فك تشفير روابط تيك توك المختصرة (`vm.tiktok.com` / `vt.tiktok.com`)، استخراج روابط الفيديو الخام بدون علامات مائية وبدقة عالية، استخراج الصوت الأصلي، وتوليد نصوص الفيرال والهاشتاجات.

## 📱 2. الأقسام والميزات الرئيسية (App Modules)

### 1️⃣ التبويب الأول: التحميل الخارق (Ultra Downloader)
- **الالتقاط التلقائي من الحافظة (Auto-Clipboard Detection)**: يكتشف تلقائياً عند فتح التطبيق وجود رابط تيك توك منسوخ ويعرض بطاقة سريعة للصق والفحص.
- **بطاقة المعاينة الغنية (Preview Card)**: تعرض صورة الغلاف (Thumbnail)، اسم الحساب، المعرف (`@creator`)، عنوان المقطع، وإحصائيات المشاهدات والإعجابات والتعليقات.
- **أزرار التحميل السريع**:
  - تحميل الفيديو بدون علامة مائية بدقة عالية (Full HD / 4K).
  - استخراج وتحميل الصوت فقط بصيغة MP3.
- **مؤشر التحميل الدائري التفاعلي (Circular Live Progress)**: يعرض النسبة المئوية الدائرية، السرعة اللحظية بالميغابايت (`MB/s`)، وحجم التحميل الفعلي.
- **معرض التحميلات المدمج (Gallery)**: حفظ في مجلد `Movies/TikTokStudio` و `Music/TikTokStudio` مع إمكانية مشاركة الفيديو فوراً إلى تطبيقات التواصل أو تشغيله.

### 2️⃣ التبويب الثاني: استوديو صناع المحتوى (Creator Studio)
- **أوقات النشر الذهبية (Golden Posting Times)**: جدول تفاعلي لأفضل ساعات النشر في الوطن العربي مع نسبة التفاعل لكل وقت وزر تفعيل الإشعارات والتذكير.
- **الهاشتاجات المتصدرة (Trending Hashtags)**: مصنفة حسب المجالات (تقنية، كوميديا، تعليم، تجارة، طبخ) مع إحصائيات حجم المشاهدات وزر **"نسخ جميع الهاشتاجات بنقرة واحدة"**.
- **أفكار فيديوهات يومية (Daily Video Ideas - Tinder-Style)**: بطاقات قابلة للتمرير تحتوي على الخاطف (Hook)، حركة الكاميرا، سر نجاح المقطع، والصوت المقترح مع زر حفظ الفكرة.
- **زخرفة البايو (Bio Styler)**: أداة حية لتحويل نصوص البايو والأسماء إلى 8 خطوط وأشكال إبداعية مقبولة رسمياً في تيك توك مع زر نسخ فوري.
- **حاسبة أرباح المشاهدات (Views Earnings Calculator)**: شريط تمرير تفاعلي لحساب الأرباح المتوقعة بالدولار استناداً لعدد المشاهدات ومعدل الـ RPM مع نصائح لرفع سعر الألف مشاهدة.

### 3️⃣ التبويب الثالث: جناح الـ VIP الملكي الحصري (VIP Lounge)
- **شاشة قفل فاخرة**: حماية متقدمة تطلب إدخال كود التفعيل والتحقق منه عبر خوارزمية C++ NDK المشفرة.
- **أكواد التفعيل المعتمدة (Master VIP Keys)**:
  - `TIKTOK-VIP-2026`
  - `CREATOR-PRO-999`
  - `VIRAL-STUDIO-GOLD`
- **الميزات المفتوحة لأعضاء الـ VIP**:
  - **مولد السكريبتات الفيرال (Viral Script Architect)**: سيناريو متكامل مقسم إلى (الخاطف في أول 3 ثوانٍ لمنع السحب، المحتوى الرئيسي، دعوة للتفاعل CTA، وتوجيهات الإخراج السينمائي).
  - **محلل الحسابات وخوارزمية الـ FYP**: إدخال بيانات الحساب لحساب معدل التفاعل الفعلي (Engagement Rate %)، تقييم الخوارزمية (A+, A, B, C)، وتقديم 5 نصائح مخصصة لتصدر الإكسبلور.

## 🛠️ 3. كيفية تشغيل وبناء المشروع (Build & Run Instructions)

1. افتح المشروع في **Android Studio (Ladybug / Iguana أو أحدث)**.
2. تأكد من توفر **Android SDK Platform 35** و **Android NDK (Side by Side)** و **CMake (3.22.1+)**.
3. قم بعمل **Gradle Sync** للمشروع.
4. اختر جهاز محاكي (Emulator) أو هاتف حقيقي يعمل بنظام Android 8.0 (API 26) فما فوق، واضغط **Run (Shift + F10)**.
